# Scanner-only baseline on the OWASP Benchmark for Python (14 October 2026)

How it was made:
```bash
bash scripts/get_data.sh
python -m codereview run data/benchmark-python/testcode --scanner-only
python -m codereview evaluate data/benchmark-python/expectedresults-0.1.csv --cwe CWE-89   # and so on
```
A test case counts as "flagged" if any alert with its CWE is in its file (the benchmark's own scoring rule).
TP = real vulnerability flagged, FP = safe code flagged (false alarm), FN = real one missed, TN = safe code not flagged.
